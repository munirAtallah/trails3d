# Trails3D — Mapping Hiking Trails in 3D with LiDAR

Course project for the **Point Cloud Mini Course**.

**The idea:** a hiker gets a 3D map of a trail from LiDAR data: its length, climbs, steep sections and tree cover, shown on their phone.

The whole project lives in one Jupyter notebook: **`trails3d.ipynb`**.

## ⚙️ Setup

**Requirements:** Python 3.10+ and VS Code (or Jupyter).

1. Clone the repo:
   ```bash
   git clone https://github.com/munirAtallah/hiking_trails-.git
   cd hiking_trails-
   ```
2. Install the libraries:
   ```bash
   python -m pip install numpy scipy scikit-learn matplotlib "laspy[lazrs]" jupyter ipykernel
   ```
3. *(Optional)* For the interactive 3D viewer, install Open3D.
   - It needs **Python 3.10–3.12**.
   - The notebook works fine without it; it uses SciPy and scikit-learn instead.
   ```bash
   python -m pip install open3d
   ```
4. Open `trails3d.ipynb` in VS Code.
   - Pick your Python under **Select Kernel**.
   - Click **Run All**.

> **Tip:** if you get `No module named ...`, run `%pip install <package>` in a notebook cell. That installs into the Python the notebook is actually using.

1. Open a dataset. A good first one is [Silver Falls State Park, Oregon](https://portal.opentopography.org/noaaDataset?noaaID=105), a hiking park.

## 🧹 How the cleaning works

The steps follow course **Lecture 2**:

| Step | What it does | Main setting |
|---|---|---|
| Hygiene | Removes NaN points, duplicates, points already labelled as noise | — |
| Voxel downsampling | Keeps one point per cube, which evens out density | `VOXEL = 0.1` m |
| Statistical outlier removal | Removes points far from their neighbours (birds, dust, sensor errors) | `SOR_K = 20`, `SOR_STD = 2.0` |
| RANSAC ground | Fits planes and labels ground points as class 2 | `RANSAC_THR = 0.15` m, `PATCH = 5` m |
| DBSCAN clusters | Groups non-ground points into objects (trees, rocks, people) | `DBSCAN_EPS = 0.6` m |

All settings are in one cell at the top of section 3 in the notebook.

### Ground on hills
- The course's RANSAC fits **one plane**. That works on a flat street but fails on slopes (Lecture 2, lab A).
- This project fits **one plane per 5×5 m patch**.
- It also ignores steep planes (walls, tree trunks) and samples from the lowest points, because ground is at the bottom.
- Set `PATCH = None` for flat street scans.

### Results so far (synthetic data)

| Data | Ground precision | Ground recall | Noise removed |
|---|---|---|---|
| Hilly trail (`PATCH = 5`) | 0.999 | 0.999 | 100% |
| Course street scan (`PATCH = 5`) | 0.94 | 0.98 | 100% |
